# 01 - Test Planning

Folder ini berisi seluruh dokumen perencanaan pengujian (test planning)
untuk aplikasi [SauceDemo](https://www.saucedemo.com).

Dokumen di folder ini menjadi **acuan utama** sebelum test case dibuat
dan dieksekusi. Semua dokumen di sini bersifat **relatif statis** -
perubahan hanya dilakukan melalui change request.
