## Tentang Repositori

Repositori ini berisi **manual testing** untuk aplikasi demo
[SauceDemo](https://www.saucedemo.com) - sebuah e-commerce sederhana yang
umum digunakan untuk latihan QA.

Dokumentasi disusun mengikuti **Software Testing Life Cycle (STLC)**
mulai dari perencanaan hingga penutupan siklus testing.

## Tujuan

- Mendokumentasikan proses manual testing secara sistematis.
- Menunjukkan kemampuan analisis, desain test case, dan pelaporan bug.
